快速开始

复制下面这段，把 你的TOKEN 换成后台生成的 Token，粘到终端回车 —— 一篇文章就发布了。

bash
curl -X POST https://www.ydxred.com/api/articles \
  -H "Authorization: Bearer 你的TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "我的第一篇 API 文章",
    "content": "# 你好\n\n这是通过接口发布的正文，支持 **Markdown**。",
    "status": "published",
    "excerpt": "一句话摘要，选填",
    "tags": ["技术", "AI"]
  }'
python · requests
import requests

BASE  = "https://www.ydxred.com/api"
TOKEN = "你的TOKEN"

resp = requests.post(
    f"{BASE}/articles",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={
        "title":   "我的第一篇 API 文章",
        "content": "# 你好\n\n正文支持 **Markdown**。",
        "status":  "published",
        "tags":    ["技术", "AI"],
    },
    timeout=30,
)
print(resp.status_code, resp.json())
javascript · fetch（Node 18+ / 浏览器）

鉴权 · 拿到 Token

除了「标签列表」是公开的，所有接口都要带 Token。

怎么拿到 Token：登录博客后台 → 设置 → API / 微信 → 点「生成 API Token」。
  • Token 是一串 60 位随机字符，只在生成时显示一次，服务器只存哈希值。
  • 丢了没法找回，重新生成即可（旧的立即失效）。
  • 把它当密码保管，别提交进代码仓库、别放进 URL。

每个请求在 请求头里带上它（不接受用 URL 参数或 body 传 Token）：

HTTP Header
Authorization: Bearer 你的TOKEN

Token 缺失或错误会返回 401。

通用约定

项目说明
Base URLhttps://www.ydxred.com/api
数据格式请求与响应都是 JSON（上传文件时用 multipart/form-data）。中文正常传，无需转义。
限速鉴权接口 120 次 / 分钟，公开的标签接口 60 次 / 分钟。超了返回 429。
归属Token 绑定到某个账号，只能操作 自己 的文章；查别人的会 404。

所有响应都是统一信封结构：

success
{
  "success": true,
  "message": "ok",
  "data": { ... }
}
error
{
  "success": false,
  "message": "参数校验失败",
  "errors": {
    "title": ["The title field is required."]
  }
}
POST/api/articles

发布文章

创建一篇文章。title 和 content 必填，其余选填。

字段类型必填说明
titlestring必填标题，最长 200 字。
contentstring必填正文，Markdown 格式。
statusstring选填draft（草稿）或 published（发布）。默认 draft。
excerptstring选填摘要，最长 500 字。不填会自动截取正文。
slugstring选填URL 别名。不填自动根据标题生成。
published_atdate选填发布时间，如 2026-07-15 10:00:00。
tagsarray / string选填标签，见下方「标签的几种写法」。
cover_imagefile选填封面图文件（multipart）。三选一。
cover_image_urlstring选填封面图公网地址，服务器自动下载落地。
cover_image_base64string选填data:image/png;base64,... 或纯 base64。
fetch_remote_imagesboolean选填是否把正文里的外链图片下载到本站，默认 true。
封面图三选一：
  • 上传文件 → 用 cover_image（整个请求改成 multipart）
  • 已有网图 → 用 cover_image_url（内网地址会被拒绝）
  • Base64 → 用 cover_image_base64
标签的几种写法（都行）：
  • JSON 数组，名称或 ID 混用："tags": ["技术", "AI", 5]
  • 逗号分隔字符串（中英文逗号/分号都认）："tags": "技术,AI,生活"
  • 不存在的标签名会自动创建。

带封面（用文件上传）

bash · multipart
curl -X POST https://www.ydxred.com/api/articles \
  -H "Authorization: Bearer 你的TOKEN" \
  -F "title=带封面的文章" \
  -F "content=# 正文\n支持 Markdown" \
  -F "status=published" \
  -F "tags[]=技术" \
  -F "tags[]=AI" \
  -F "cover_image=@/path/to/cover.png"
GET/api/articles

文章列表

分页列出你自己的文章。支持按状态和关键词过滤。

查询参数说明
statusdraft / published，不填则全部。
q按标题模糊搜索。
per_page每页条数，默认 20。
page页码，默认 1。
bash
curl -H "Authorization: Bearer 你的TOKEN" \
  "https://www.ydxred.com/api/articles?status=published&per_page=20&page=1"

返回的 data 里含 items 数组和 pagination（current_page / last_page / per_page / total）。列表默认不含正文，需要正文加 ?include_content=1。

GET/api/articles/{id 或 slug}

文章详情

用文章 ID 或 slug 取单篇，含正文。

bash
curl -H "Authorization: Bearer 你的TOKEN" \
  https://www.ydxred.com/api/articles/42
PUTPATCH/api/articles/{id 或 slug}

更新文章

只传要改的字段，其它保持不变。字段和「发布文章」一致。

bash
curl -X PATCH https://www.ydxred.com/api/articles/42 \
  -H "Authorization: Bearer 你的TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "title": "改个标题", "status": "draft" }'
DELETE/api/articles/{id 或 slug}

删除文章

删除一篇文章（软删除）。

bash
curl -X DELETE https://www.ydxred.com/api/articles/42 \
  -H "Authorization: Bearer 你的TOKEN"
POST/api/posts

发动态

发一条「动态」（类似微博/说说）。

字段类型必填说明
contentstring必填内容，最长 2000 字。
statusstring选填draft / published，默认 published。
imagesarray选填图片 URL 数组，最多 15 张（用下面的图床接口先拿到 URL）。
bash
curl -X POST https://www.ydxred.com/api/posts \
  -H "Authorization: Bearer 你的TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "随手发条动态",
    "images": ["https://www.ydxred.com/storage/uploads/a.jpg"]
  }'
POST/api/upload

上传图片

上传一张图片，返回可直接用在 Markdown / 动态里的 URL。文件、网址、Base64 三选一。

bash · 上传文件
curl -X POST https://www.ydxred.com/api/upload \
  -H "Authorization: Bearer 你的TOKEN" \
  -F "image=@/path/to/photo.png"

或用 JSON 传网址 / Base64：{"image_url": "..."} 、{"image_base64": "data:..."}。返回：

响应
{
  "success": true,
  "data": {
    "path": "uploads/xxxx.png",
    "url": "https://www.ydxred.com/storage/uploads/xxxx.png"
  }
}

错误码

失败时 HTTP 状态码 + success:false，看 message 和 errors 定位问题。

状态码含义怎么处理
401未授权Token 缺失或错误。检查 Authorization: Bearer 头。
404找不到文章不存在，或不属于当前 Token 的账号。
422参数校验失败看 errors 里每个字段的原因，补齐或修正。
429请求过快触发限速（120 次/分）。放慢重试。
